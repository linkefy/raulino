# Dr. Raulino Brasil — Site

Site estático (HTML puro), pronto para GitHub Pages.

## Arquivos principais

- `index.html` — Home (desktop)
- `index-mobile.html` — Home (mobile)
- `projeto-leozinho.html` — Página do Projeto Leozinho (desktop)
- `projeto-leozinho-mobile.html` — Página do Projeto Leozinho (mobile)
- `support.js` — runtime necessário para todas as páginas (mantenha na raiz)
- `assets/` — imagens e logos
- `uploads/` — vídeos e fotos de resultados/campanha

## Publicar no GitHub Pages

1. Crie um repositório e envie todos os arquivos desta pasta para a branch `main` (mantendo a mesma estrutura de pastas).
2. Em Settings → Pages, selecione a branch `main` e a pasta raiz (`/`).
3. Aguarde a publicação; a URL será `https://SEU-USUARIO.github.io/SEU-REPOSITORIO/`.
4. Atualize `sitemap.xml` e `robots.txt` com o domínio final.

## Observações

- Antes de trocar `SEU-DOMINIO-AQUI` no `sitemap.xml`/`robots.txt`, defina a URL final do site.
- Pendências de conteúdo marcadas no site (ex.: fotos/registros "a enviar", perfil do Instagram "a confirmar") devem ser revisadas com o cliente antes da publicação definitiva.
